SETUP GUIDE FOR RACO SCRIPT (SIMPLIFIED)
======================================

STEP 1: Grant Permissions (Run Once)
----------------------------------
1. Open your terminal.
2. Navigate to the folder where you saved the script.
   (Example: cd ~/Downloads or cd ~/Documents)
3. Run this single command to allow the script to run without a password:

echo "$USER ALL=(ALL) NOPASSWD: $(pwd)/Raco-Main.sh" | sudo tee /etc/sudoers.d/raco-control

(If asked for a password here, enter your user login password once).


STEP 2: Set Keyboard Shortcuts
----------------------------------
Go to your System Settings -> Keyboard -> Shortcuts and add these commands:
(Note: Replace "/path/to/" with the actual location of your script, e.g., /home/yamada/)

For Performance Mode:
sudo /path/to/Raco-Main.sh 1

For Balanced Mode:
sudo /path/to/Raco-Main.sh 2

For Powersave Mode:
sudo /path/to/Raco-Main.sh 3

Example:
sudo /home/yamada/Raco-Main.sh 1
